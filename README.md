Very easy to use 3D animation software made by Claude, found it so good that i posted it here. 

The animation is extremely easy, you simply make a scene, add light, characters and move them to how you want (does not support files that come with animations) and move the "movie cam" to where you need and press add scene, then you can just keep doing that over and over, the program will add the bits in the middle and you can say how long you want that "Middle bit" to be.

current features: 
Dual camera (movie + free cam) 
Volumetric fog, explosions and smoke
Heat effect 
Dynamic sun
Dynamic Light block
fps and resolution export adjustments.
auto animate 
save and load project
scale

Minumun specs: 
- ANY modern CPU
- 4GB RAM
- RTX 2060 (for hardware acceleration and modern RTX series software integration) (This will run on much weaker thing but expect glitching with high light and effects)

Recommended:
- Still any CPU
- 8-16GB RAM
- RTX 4050
